Colorize

A manga/lineart colorization variant of EasyControl. Uses the same extended self-attention cond stream architecture, but with different training data: the target is an existing color illustration (reusing latent + caption caches from post_image_dataset/lora/), and the condition is a synthetic mangafied version of that image (XDoG lineart + algorithmic screentone), cached to a separate cond_cache_dir.

The text channel is reduced to color-only captions (hair/eye/garment colors), cached to a separate text_cache_dir, so the prompt carries the one variable B&W can't — hue. At inference, an empty prompt auto-colorizes; a color prompt (e.g. pink hair, blue eyes) steers the palette.

Usage

make easycontrol-staging    EASYADAPTER=colorize   # 1) mangafy cond tree
make easycontrol-preprocess EASYADAPTER=colorize   # 2-3) VAE-encode cond + color text
make easycontrol            EASYADAPTER=colorize   # train
REF_IMAGE=page.png make test-easycontrol EASYADAPTER=colorize   # inference

In the GUI, the EasyControl tab's Variant dropdown lists Colorize. Its config file is configs/easycontrol/colorize.toml (a descriptor file with [staging]/[preprocess]/[training] sections).

Full design notes (caption policy, screentone bands, inference settings) live in easycontrol_adapters/colorization/README.md.
