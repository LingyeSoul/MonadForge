Preprocessing

This tab builds the caches training reads:

Caching — resizes each image to a native-aspect size inside its tier's token band (no crop) and tokenizes captions through Qwen3 + T5, writing {stem}_{WxH}_anima.npz latents and {stem}_anima_te.safetensors sidecars. When shuffle variants > 0, each TE cache holds N captions and the dataloader samples one per training step (turn on use_shuffled_caption_variants in your method config to use them).

Curation lives in anime_tools — auto-tagging, position clauses and SAM3/MIT masks run from the anime_tools panel, not from here. This tab never starts those stages, even when configs/preprocess.toml turns one on. Masks under post_image_dataset/masks/ are used only when masked_loss = true in the method config.
