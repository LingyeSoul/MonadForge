EasyControl

Extended self-attention image conditioning adapter. Frozen DiT with per-block cond LoRA on self-attention (q/k/v/o) and FFN (layer1/layer2), plus per-block scalar additive logit bias b_cond (controls how much softmax mass the cond positions can claim). The reference image is VAE-encoded and patch-embedded via the DiT's x_embedder into condition tokens that flow through every block alongside the target stream; target self-attention attends to keys from both itself and the cond stream.

Training launches via make easycontrol. Reuses existing VAE latent cache as cond input — no separate sidecar cache needed. Run make preprocess first if VAE latents aren't cached, then make easycontrol.

Inference uses make test-easycontrol REF_IMAGE=<path> PROMPT="...". The cond stream is deterministic across denoising steps — at inference, a precomputed KV cache eliminates per-step recomputation of the cond stream.

Variants
• default (ref==target) — the condition is the reference image itself.
• colorize — manga/lineart colorization. Condition is a synthetic mangafied B&W version (XDoG lineart + algorithmic screentone), target is a color illustration. See the separate Colorize guide.

Trainable parameters (default r=16, D=2048, 28 blocks): ~14.7M. Set apply_ffn_lora=0 to drop FFN LoRA, halving the count.

Key settings: b_cond_init (initial bias, default -10), easycontrol_drop_p (CFG dropout probability, default 0.1), cond_res_scale (position-aware interpolation scale, <1.0 speeds up training). See docs/experimental/easycontrol.md.
